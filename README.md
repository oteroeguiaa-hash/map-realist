# Map Realist

Jeu d'exploration sur une île tropicale volcanique **photoréaliste** : buggy, avions, jungle dense, lagune avec poissons, cascade et volcan. Il est construit avec **Unreal Engine 5.8** par Claude Code, relié à l'éditeur via MCP.

- Cahier des charges : [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- Installer le PC et relier Claude à Unreal : [docs/INSTALLATION_PC.md](docs/INSTALLATION_PC.md)
- Règles de travail pour Claude : [CLAUDE.md](CLAUDE.md)
- Journal de construction : [docs/JOURNAL.md](docs/JOURNAL.md)
- Assets et licences : [docs/ASSETS.md](docs/ASSETS.md)
